# NFC 暦占い

NFCタグにURLを書き込んでおき、スマホをかざすと今日の運勢の札が引けるWebページです。
`index.html` 1枚で動きます（GitHub Pages などに置くだけ）。

## 機能
- 今日の札（大吉〜末吉）：本命星が今日の九星盤のどこにいるか、六曜・十二直・選日から決定
  - 天赦日・一粒万倍日は特別札の演出
- 今日の御守り言葉：ことわざ・論語・老子・禅語などから。本命星ごとに全64語を一巡し、前日と同じ言葉は出ない
- 本命星・月命星（生まれた年・月の節入り日で判定）、最大吉方（両方の星に吉の方位）
- 今日のいい時間（時盤）、九星盤、最近7日間の運勢
- 明日の暦（六曜・吉日だけ先に表示）
- 吉日カレンダー（天赦日・一粒万倍日・寅の日・巳の日・不成就日、開運日の目安）
- ほかの人の生年月日で占う＋自分との相性（五行の相生・相剋）
- 季節の札図鑑：二十四節気ごとに絵柄が変わる札を集める（24節気×5札＝120枚）
- 身代わり守り：7日連続で1つ（最大2つ）。引き忘れた日の連続日数を守る
- 次の大きな日：天赦日・一粒万倍日・開運日・次の季節の札までのカウントダウン
- 札の記録・称号（このスマホの中だけに保存）
- 画面を「今日・暦・記録・ツール」のタブで切り替え
- 便利ツール：日数・営業日の計算（土日祝、金融機関・官公庁の年末年始も選べる）、祝日一覧（2016〜2099年。振替休日・国民の休日を含む）、西暦・和暦の変換（元号の切り替わり日まで対応、コピー可）、年齢早見表（干支・数え年・学年・長寿祝い・厄年）
- 今日の札を画像にしてシェア／保存
- ホーム画面に追加・オフライン対応（`manifest.webmanifest` / `sw.js`）
- 開いたまま日付が変わると自動で読み直し

## 暦データの根拠と検証
| 項目 | 根拠 |
|---|---|
| 二十四節気・節入り日 | 太陽黄経（15度刻み）の天文計算、日本時間 |
| 旧暦・六曜 | 朔（新月）と中気による天保暦の規則。六曜は（旧暦の月＋日）÷6の余り |
| 干支 | ユリウス日からの計算 |
| 日家九星 | 冬至・夏至に最も近い甲子日で陽遁（一白から順行）・陰遁（九紫から逆行）を切替 |
| 十二直 | 節月の地支と日の地支（節入り日は前日の直を繰り返す） |
| 一粒万倍日・天赦日・不成就日など | 伝統的な暦注の表 |

暦データは `tools/gen_data.py` で作成しています（2025-12-01〜2031-11-19）。
2031年12月以降は日家九星の「閏」（切替の間隔が180日にならない時期）に入り、流派によって計算が分かれるため、その手前で止めています。

`tools/verify.py` で、`index.html` の暦データと節入り日表（1900〜2100年）を
天文計算ライブラリ [ephem](https://pypi.org/project/ephem/) で計算し直して照合できます。

```
pip install ephem
python3 tools/verify.py
```

あわせて、2026年の天赦日（3/5・5/4・5/20・7/19・10/1・12/16）が公開されている一覧と一致することを確認しています。

暦注や九星気学は昔からの習わしで、科学的な根拠があるものではありません。
